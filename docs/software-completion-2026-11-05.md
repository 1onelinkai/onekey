# 软件功能补全与验收记录

日期：2026-11-05。范围：概览、API Keys、服务商和模型、请求记录、客户端检测、安装、升级、卸载、配置预览/应用/恢复。截图作为缺陷线索，不作为唯一检查范围。

## 已补全

- **Agent 升级**：标准 OpenCode 独立安装接入官方更新器；托管 Grok 接入官方稳定版本查询和固定版本下载。更新前检查安装位置，保留旧程序，更新后校验实际版本，失败恢复。单个客户端检测异常不再中断全部检查。
- **服务商编辑**：真实保存名称、地址和协议；编辑时密钥留空保留原密钥。
- **模型管理**：内联改名、启用/停用、默认选择接通持久化；默认模型真正用于配置选择。停用默认模型时清除默认状态。
- **模型同步**：按 OpenAI/Responses 或 Anthropic 协议鉴权；支持 Anthropic 分页、去重、超时和响应校验。完整校验后批量保存，保留人工名称、启用和默认状态。并发写入串行，避免模型丢失。
- **配置流程**：统一入口状态重置；切换来源、密钥或服务商时清除旧预览和测试状态；拦截过期异步响应；本地刷新实际查询对应服务商。
- **概览和请求记录**：首页使用独立组织请求总数；请求页区分未登录、加载、失败和空结果；连接状态、客户端数量和桌面/终端类型按实际数据展示。
- **文档与流程脚本**：纠正适配能力说明；桌面流程脚本覆盖服务商编辑、模型同步/改名/默认选择及配置预览、应用和恢复。

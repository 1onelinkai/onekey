# OneLinkAI 产品介绍页

以 AI 工具安装、模型接入、平台 Key 与配置保护为核心，制作中文介绍落地页。

视觉使用暖白纸色、墨黑字体和少量朱橙点缀，配合大留白、细线、轻量动效与低饱和产品插画。页面顺序：导航、品牌首屏、可交互工作台预览、工具生态、三项核心优势、三步使用方式、常见问题、行动入口与页脚。

浏览器默认显示介绍页，`?app` 保留工作台网页预览；检测到 Electron 的 `onelinkDesktop` 后自动加载原工作台。两个页面独立加载样式，避免互相影响。所有工作台入口均进入现有应用，无虚构下载地址。

演示支持工具搜索、已配置筛选、页面切换与配置确认。演示数据只保存在 React 内存中，明确说明本机检测、安装与配置必须使用桌面客户端。保留实际平台支持范围说明，不承诺未经验证的平台能力。

验证包括 Vite 生产构建、现有单元和集成测试、浏览器交互验证与移动端布局检查。

# 服务商模型按行展示

模型列表从横向标签改成纵向列表，每个模型独占一行。名称和请求 ID 在左侧分层展示，相同内容只显示一次；上下文和输出规格作为次要信息。

“已启用”“已停用”“默认模型”是独立状态标签。右侧操作使用有边框、背景和悬停反馈的真实按钮，文字为“停用 / 启用”和“设为默认”；默认模型或停用模型的默认操作禁用。编辑和删除图标也有固定尺寸和边框，所有操作在保存期间禁用。

窄窗口内每个模型仍占独立一行，按钮移到该行下方右侧，长模型 ID 自动换行。保留添加模型、拉取模型和客户端配置逻辑。

验证：更新现有 Electron 流程中的模型选择器，检查停用、启用、设为默认以及编辑和配置流程；确认多个模型纵向排列，操作按钮有边界，长 ID 和窄窗口不产生横向溢出。

# 服务商表单改为弹窗

目标：模型服务商页面优先展示服务商和模型，移除常驻的六字段新增表单。

采用工具栏“添加服务商”按钮打开紧凑弹窗，编辑按钮复用同一弹窗。相比页面展开表单，弹窗不会推移当前列表，操作完成后能回到原位置。页面无服务商时提供“添加第一个服务商”入口。

弹窗默认展示名称、地址、协议和 API Key。备注、官网链接置于“更多信息”折叠区；编辑已有可选信息时自动展开。保存成功关闭并刷新列表；失败保留输入并展示错误；取消或 Esc 关闭且不保存，再次新增重置表单。编辑密钥留空时保留已有密钥。

键盘进入时聚焦名称，Tab 保持在弹窗内，关闭后将焦点还给原入口。保存期间禁用编辑和关闭。小窗口使用单列字段，弹窗内部可滚动。

验证采用现有 Electron 端到端流程，覆盖新增、取消后重开、编辑、可选项、密钥保留、键盘操作，以及后续拉取模型和配置客户端流程；构建并检查实际布局。

# 全软件功能补全与验证

范围：概览、API Keys、服务商、请求记录、配置预览/应用/恢复、检测、安装、升级、卸载。截图仅作为缺陷线索。

实施与验收：
1. 补全标准 OpenCode 独立安装和托管 Grok 的升级；目标版本固定、位置复检、原程序备份、失败恢复。临时 HOME 验证，不升级本机客户端。
2. 服务商模型列表根据协议鉴权，分页去重、完整校验后批量持久化；补齐编辑服务商和真正生效的默认模型。隔离存储/HTTP 测试。
3. 统一配置入口，防止旧预览、旧请求和错误协议残留；模型刷新按实际来源加载。
4. 首页独立加载组织请求总数；请求页区分未登录、预览、加载与失败；纠正固定连接状态和支持数量。Electron UI 流程验证。
5. 核对其余入口和文档，记录经过证实的限制；全量测试、构建、桌面 smoke 和流程测试。

不使用猜测的 Gemini 原生协议或 VS Code SecretStorage 格式冒充自动配置支持。外部包管理器安装保留明确来源限制。

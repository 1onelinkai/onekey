# OneLinkAI 软件自身更新设计

目标：启动检查软件本身；用户选择下载全量安装包，完成后确认重启安装，覆盖应用文件，保留用户数据。

复用已有 Electron/electron-builder 打包。Windows 使用 NSIS，Linux 使用 AppImage。macOS 根据用户确认后的发布约束，只生成和上传一个 DMG，官网下载和自动更新共用该文件；客户端下载后验证应用签名、身份、版本与架构，本地转换临时 ZIP，复用 Squirrel.Mac 安装，不维护应用替换助手。

与 Agent 更新模块独立，主进程选择 HTTPS feed 的系统、架构路径，渲染进程只读状态和发起确认。默认关闭下载、退出安装、差分下载、降级和预发布。无更新不弹窗，失败可重试，重复点击合并；macOS 安装退出前解除关闭到托盘的拦截。

macOS 支持现有 JSON 版本接口（version、downloadUrl），允许 data 包装；实际字段不同在客户端映射。build/software-update.json 配置现有接口，运行时环境变量可覆盖。不要求后台新增 ZIP 上传或 YAML 上传能力。保留标准清单作为可选兼容方案。发布工具基于最终签名、公证后的 DMG 生成校验信息，保证和官网下载字节一致。

验证状态机授权、失败、并发和禁用环境；验证挂载、签名、版本、架构、卸载失败保护和 JSON 适配；检查发布整理的校验与目录约束。用真实签名 DMG 验证转换与本地原生桥接服务，复核解压后签名。运行已有测试、生产构建和 Electron smoke。真实跨版本安装需对接后台后完成发布验收。

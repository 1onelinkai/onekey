# 配置模型默认值、手动更新提示与 Key 切换修复

进入管理配置时，优先选择该客户端配置记录中的当前模型；仅在当前来源的可用模型列表中选择。当前模型不可用时使用来源默认模型或列表首项，并显示说明。切换来源和刷新时保留仍然可用的已选模型；切换客户端时改为该客户端当前模型。异步加载继续由请求序号隔离旧响应。

配置来源以第一个冒号分隔来源类型和完整 ID，避免 `key:组织ID:记录ID` 截断为组织 ID。个人工作空间 Key 同样处理。

检测到新版本而当前安装不支持一键更新时，卡片显示“有新版本 · 需手动更新”；明确不支持版本检测的桌面客户端显示“需手动更新”。点击后说明安装来源限制，并提供打开客户端和官方下载入口。

验证：来源 ID 与模型选择单测；Electron 配置流程检查来源切换、当前模型回选、手动更新入口；构建及已有相关测试。

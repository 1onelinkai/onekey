# 服务商与模型分别支持多协议

服务商保存支持的协议集合，以及用于模型列表拉取的默认协议。所有协议共用服务商地址与密钥。添加和编辑服务商时多选支持的协议，选择默认拉取协议。

模型保存独立的协议集合，必须为服务商协议的非空子集。旧模型沿用原来的协议；修改默认拉取协议不会扩展旧模型的能力。拉取窗口可切换拉取协议，新导入模型仅记录本次拉取协议；重新选择已有模型保留原设置。手动添加和编辑模型可设置多个协议。服务商移除仍被模型使用的协议时，提示先调整模型。

一键配置按模型协议与应用支持协议取交集，切换模型或应用时自动选可用协议，无交集时提示并禁用预览与测试。主进程再次验证协议，避免绕过界面写入不兼容配置。

验证覆盖旧数据兼容、多协议保存、子集约束、原子导入、默认协议切换、界面选择和无兼容协议时的阻断。

# OneLinkAI 落地页：连接控制台

用户已确认按参考研究后的“连接控制台”方向重做，取代居中标题、双按钮、产品截图和三列卖点的旧布局。

## 设计

纸白、墨黑与集中使用的钴蓝。首屏左侧清晰解释产品，右侧以工具连接为核心构图，带有工具、模型、配置三个可操作步骤。工具目录使用连续编号和分隔线，保持原工具图标。配置保护通过深色变更对照和轻微倾斜的备份凭条表达。后续使用步骤、原生 FAQ、横向品牌收尾保持不同阅读节奏。

## 行为与范围

- 四种工具配置示例：Claude Code、Codex、OpenCode、Zed；切换工具重置模型与流程状态。
- 模型选项仅为示例，不声称反映平台真实可用模型。
- 配置预览随所选工具、模型更新；完成操作仅更新当前 React 页面状态，不接触真实文件或凭据。
- VS Code 单独注明仅支持安装、检测。Hermes 等其他工具入口指向能力说明。
- 原有 Electron / ?app 路由保留。无需添加下载接口或修改桌面业务。
- 标签页支持左右方向键与 Home/End；FAQ 使用原生 details；减少动态效果偏好下隐藏运动指示点。

# 已安装 Agent 的卡片启动入口

每张已安装卡片增加独立打开按钮，保留配置、查看文件和卸载操作。桌面应用优先按检测到的应用包交给系统打开；只有命令入口的 CLI 在新系统终端会话中启动。DSH CLI 使用最近一条有效配置记录的 profile，未配置时使用 web。

IPC 只接受客户端标识，由主进程重新检测路径。终端命令对文件路径和参数逐项引用，补齐托管命令及 Node 路径。macOS 将私有临时 .command 文件交给 Terminal 打开，脚本退出时自行清理，Windows 使用独立 PowerShell 窗口，Linux 使用系统 x-terminal-emulator。启动结果表示请求已经交给系统，界面不声称模型已经连接成功。

验证覆盖桌面包优先、未安装拒绝、终端参数及特殊字符引用、Windows 编码参数、DSH profile 选择、系统启动失败，以及真实渲染器经 IPC 发送启动请求。

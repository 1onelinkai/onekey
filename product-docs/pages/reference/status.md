# 当前能力、验证范围与已知限制

版本基线：**0.3.2**；源码核对日期：**2026-11-11**。本页不会把旧验收报告里的版本称作今天的最新发布。

## 能力状态

| 能力 | 当前实现 | 边界 |
| --- | --- | --- |
| 平台登录 / 恢复 | 独立窗口接入 SSO，本地加密会话 | 首次显示登录状态不等于服务端在线验证 |
| BYOK | 无需平台登录，服务商与模型本地持久化 | 无云同步，无按组织分库 |
| 模型拉取 | 弹窗、搜索、启发式分类、确认选择 | 普通 OpenAI 自定义分页不通用；不验证所有模型能力 |
| Agent 检测 | 16 个已知 Agent 入口、命令和 macOS 包 | 不枚举整个硬盘，不保证发现所有实例 |
| 版本检查 | 异步、定时、聚焦触发 | 发布渠道可能滞后，预览版渠道不自动匹配 |
| 一键安装 | CLI 有 macOS/Windows分支；桌面仅macOS | 实机验收主要 macOS ARM；Linux 自动安装未接入 |
| 一键更新 | 托管或少数已识别标准安装 | 不覆盖未知 / 外部包管理器程序 |
| 卸载 | 按来源移除一份安装，保留资料 | 不是通用清理器，不保证跨步骤完全回滚 |
| 原生配置写入 | 16 个适配器入口，预览、备份、回读和恢复 | 第三方格式变动需持续维护 |
| 配置查看 | 脱敏、只读、多文件 | 不合并所有运行时覆盖；不是原文编辑器 |
| 模型测试 | 小型真实请求 | 不覆盖流式、工具、视觉和长会话全能力 |
| Zed / VS Code Key | 用户在目标应用内手动保存 | 工作台不会自动写它们的系统凭据 |
| 本软件自身自动更新 | 没有完整自动更新链路 | Agent 更新能力不能外推到工作台自身 |

## 已记录的验证和证据强度

- 仓库历史安装报告记录 macOS ARM 上真实安装、版本运行和检测，见 `docs/installation-validation.md`。这份报告有自己的日期和当时版本，不能当作今天重跑结果；其中 Grok 的早期“不支持”结论已被后续实现替代。
- 版本升级报告记录隔离 HOME 下的真实 Codex 升级，及部分其他来源的模拟 / 单元验证，见 `docs/agent-updates.md`。并未宣称每个 Agent 都实际从旧版升级过。
- 当前仓库有 Agent、安装、更新、卸载、配置查看、登录与持久化测试。测试覆盖异常路径，不代表真实 Key 的收费推理和所有硬件平台通过。
- 新增 `desktop:test-persistence` 使用真实 Electron、临时 userData、实际界面保存、完全结束进程后重启，再核对提供方与模型。它不是只新建一个内存 store 的测试，也不会拿真实用户 Key 做实验。
- 本文档生成检查在临时目录调用15个真实配置适配器，只证明示例与生成逻辑一致；没有据此声称第三方应用已真实打开并完成聊天。

## 必须直说的限制

### 资料加密与 Agent 凭据不等价

本地 Key 和密文放在同一用户目录；有权限读两者的程序可以解密。Agent 原生配置及备份中仍可能存在明文 Key。详见[存储说明](/principles/storage)。

### 没有多进程数据锁

同一进程串行写 store，但多份工作台可以竞争同一文件。当前不应同时打开多份来编辑服务商。开发模式和正式打包版本的数据目录也可能不同。

### 跟随的发布线不同

npm 用 latest，Hermes初装固定main提交而更新stable，部分桌面参考Cask；版本差异需要按来源解释。不能承诺“始终第一时间发现厂商最新构建”。

### 配置不是实时同步

编辑 BYOK 资料、删除服务商或退出登录，不会撤销已写到 Agent 的凭据。用户在 Agent 内修改配置也不会自动回流为工作台的永久模型资料。

### 协议兼容不等于功能兼容

同协议的服务商仍可能不支持工具、图片、特定推理参数或某个模型别名。列表、测试、写文件和目标应用运行要分别验收。

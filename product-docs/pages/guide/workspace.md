# 界面与日常操作

## 概览与 Agent 卡片

首页集中展示已安装 Agent，可切换“已安装 / 全部”。卡片上的版本、当前配置记录、安装状态和更新状态来自不同数据源，不能彼此替代。

“已配置 N 个”和“当前模型”主要关联 OneLinkAI 保存的配置历史；它们不是持续读取所有客户端运行时状态的监视器。手工修改文件或在 Agent 内切换模型后，以[本机配置查看器](/principles/inspector)和目标客户端内的结果为准。

信息图标可用鼠标悬停、键盘聚焦或点击打开，展示安装来源、升级能力和原因；较长内容在浮层内滚动。

## 配置弹窗

应用选择、模型来源、模型、高级参数和本机配置查看集中在同一工作流中。切换应用后会按能力表筛选字段。右侧高级设置和只读配置查看帮助对照当前文件，查看内容不会直接写回磁盘。

参数发生变化后应重新测试和预览，避免使用旧计划提交。预览令牌是主进程内存里的临时引用，不是 API Key，也不是可复用的永久授权。

## API Keys

读取当前平台组织的 Key、状态和额度，支持查找与刷新。平台 Key 的创建、吊销、计费策略仍在平台控制台管理。桌面版不通过假数据补齐服务端未返回的统计。

## 模型服务商

维护 BYOK 地址、协议和模型，支持编辑备注和官网链接。拉取模型先选择再确认，服务商与模型会在本地持久化。与平台 Key 页不同，这里的资料不要求登录。

## 配置记录

每次成功写配置会保存时间、Agent、模型、目标文件、写后哈希、备份索引和恢复状态。配置记录是文件操作历史，不是模型请求记录。

恢复会核对当前文件是否仍是当次结果。若多个记录先后写了同一文件，通常需要先撤销最近的相关操作，再考虑更早记录。恢复不会自动将 BYOK 模型列表一起回退。

## 请求记录

展示平台 API 返回的请求日志，可按组织、Key、模型、供应商、模型类型和时间过滤并分页。它不是对本机所有网络流量的抓包。直接调用第三方服务商的 BYOK 请求不会因为使用了 OneLinkAI 配置就自动出现在平台日志中。

## 状态栏与退出

关闭主窗口会隐藏，安装等主进程任务仍可能继续。状态栏菜单可以重新打开窗口、触发检测或退出。真正退出会终止进程及内存任务；安装状态日志不是一个可跨重启续跑的任务数据库。

右上角状态表示桌面桥接可用。缺少桥接时显示网页预览；不要把“桥接存在”当作服务器和每个客户端均健康的检查。

# 平台接口、额度与请求记录

平台页通过已有 OneLinkAI 服务接口读取数据。它不从所有 Agent 的本地对话目录推算账单，也不把 BYOK 请求自动上传成平台日志。

## API 的通用行为

平台请求发往 `https://api.onelinkai.cloud`，默认 JSON POST，部分端点 GET。设置 `Cache-Control: no-store`、客户端来源和环境头，并在认证请求附 Bearer token 与用户标识。

每次请求超时 30 秒，禁止重定向。接受响应业务 code 为 0 或 200；HTTP 401 可刷新 token 并重试一次。接口字段映射以当前实现为准，平台后端变化可能造成列表或统计读取失败。

## 额度怎样显示

钱包接口提供可用额度、预算上限、使用额、周期与组织余额。代码把可解析数字转换成数值，缺失返回 null，不造一个 0 来假装知道。

不限额依据预算 / 周期状态判断；进度基于 used / limit 并限制在 0–100%。个人钱包和组织个人钱包采用不同接口。旧账号端点返回 404 时允许没有钱包信息，不因此使 Key 列表不可用。

金额和用量来自平台口径，不是桌面实时计费引擎。刷新周期、数据延迟、最终结算规则应由平台账单解释。

## Key 状态与预算

Key 列表通过 key metadata 转换停用、到期、预算和状态标签。详情再次校验，避免在列表很久没刷新的情况下直接使用失效 Key。前端按钮禁用只是交互提示，实际授权检查仍在主进程和服务端。

## 请求筛选与分页

日志列表 `/log/user/call/list` 接受当前组织范围、页码、每页数量、Key、模型、供应商、类型、起止时间。

- 页码至少为 1；每页接受 20、50、100，其他值回到 50。
- ID 过滤去重，每类最多 50 个。
- 时间格式为 `YYYY-MM-DD HH:mm:ss`，要求起始不晚于结束；当前客户端按本机时间解析，不额外自动做跨时区换算。
- 传 Key 筛选时必须属于当前组织缓存。
- 详情 ID 限字母数字、下划线与短横线，最长 200 字符。

平台返回 records、total，工作台映射时间、模型、输入输出 token、费用和状态；详细字段按 `src/request-fields.json` 白名单处理。缺失字段显示空或占位，不凭模型名推算。

## 详情、切换组织和并发

筛选选项分别读取供应商、模型与类型字典。打开详情调用单条日志接口。切换组织或退出后，旧界面请求通过代次判断避免覆盖新页面数据；服务器仍是权限边界。

本地配置历史与平台日志互不替代：写过文件不表示已经发生调用；平台有日志也不表示该请求一定来自这台电脑。

## BYOK 的可见性

如果 BYOK 指向独立服务商，实际 Agent 请求由该服务商处理，OneLinkAI 平台页自然不拥有它的日志和账单。若用户自己把 BYOK 地址指到 OneLinkAI 平台，则按该地址与 Key 的真实平台行为决定是否产生记录，不按“来源按钮”魔法区分。
